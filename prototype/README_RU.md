# Qazaq Voice — Windows Desktop UI Prototype

Проект: **Development of an Intelligent Voice Control System in the Kazakh Language Based on Neural Networks**.

Задача YouTrack: KVC-8 — Develop UX Prototype. Проект: Astana IT University.

## Как показать на созвоне за 10 секунд

1. Дважды нажмите `index.html`: интерфейс откроется в браузере без установки зависимостей.
2. Либо двойным щелчком запустите `LAUNCH_WINDOWS_WINDOW.bat`: откроется отдельное окно Edge в режиме приложения, без обычных вкладок браузера (если Edge установлен).
3. Нажмите «Калькуляторды аш» → увидите `open_calculator` и результат.
4. Нажмите «Дыбысты көтер» → `increase_volume`.
5. Введите `Компьютерді өшір` → пример отказа для неподдерживаемой команды.
6. Нажмите «Демо тыңдау» → покажите состояние Listening (симуляция).

## Что уже реализовано

- Дизайн интерфейса Windows-ассистента (планируемый desktop UI).
- Состояния Ready / Listening / Processing / Success / Error.
- 7 демонстрационных сценариев на казахском.
- Ввод текста и простейшая демонстрационная классификация команд по ключевым словам.
- История симулированных действий и обработка неподдерживаемых команд.
- Адаптивная вёрстка, локальная работа без подключения к интернету.

## Что ещё НЕ реализовано

- **Нет** работающего распознавания речи (ASR).
- **Нет** захвата звука с микрофона: «Демо тыңдау» только демонстрирует состояние интерфейса.
- **Нет** управления Windows, открытия приложений или изменения громкости. Интерфейс показывает только **симуляцию** результата.
- Это **UI/UX-прототип**, а не готовый голосовой ассистент.

## Как позднее стать настоящим Windows desktop app

Возможны PySide6 (нативное Qt-приложение) либо desktop webview-оболочка. Нейросеть ASR, обработчик intent, allowlist системных действий и Windows API реализуются отдельными компонентами. Утверждённого производственного стека пока нет.

## Как загрузить в общий GitHub

Скопируйте файлы из этой папки в `prototype/` репозитория `kazakh-voice-control-system`, заменяя старый `prototype/index.html`.

Не забудьте сделать отдельную ветку/PR от имени реального исполнителя и привязать изменения к задаче KVC-8.

Пример коммита: `KVC-8: Add Windows desktop voice assistant UI prototype`.

Если прототип собрал/изменил Нурасыл, коммит должен сделать Нурасыл из своего аккаунта, а не другой участник от его имени.
