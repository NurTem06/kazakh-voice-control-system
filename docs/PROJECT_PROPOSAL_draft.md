# Project Proposal (draft for approval)

**Title:** Development of an Intelligent Voice Control System in the Kazakh Language Based on Neural Networks

**Problem.** Accurate and reliable Kazakh voice commands require more than generic speech-to-text. The project will connect a neural recognizer to a constrained and safe action protocol and then measure end-to-end performance.

**Intended users (proposed).** Kazakh-speaking users of a demonstration web interface. Validate this with real discussions.

**Aim.** Create and evaluate a neural Kazakh voice-control prototype with clear failure handling.

**Objectives.** Validate user demand; compare Kazakh ASR candidates; specify API and intent actions; implement browser + backend + ASR adapter; test speech and intent accuracy, reliability, privacy, and latency.

**MVP (provisional).** Recognize short Kazakh commands, map to SHOW_HELP, OPEN_SECTION, SET_THEME, CANCEL or UNKNOWN and reflect the safe action in the browser UI.

**Out of scope for MVP.** Financial operations, arbitrary OS commands, background listening, real device actuation and unsafe remote controls.

**Expected outcome.** A reproducible demo and evaluation report, including error examples and comparative baselines. At 24 October checkpoint, documentation/architecture/prototype evidence only; no complete application is claimed.
