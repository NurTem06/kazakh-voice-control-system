# Как сделать настоящий PDF со скриншотами YouTrack

1. Откройте действительный YouTrack-проект и доску, где видны колонки с настоящими задачами. Сделайте скриншот Win+Shift+S.
2. Откройте 3–5 наиболее содержательных задач, по возможности разных участников, чтобы были видны Summary, Assignee, Priority, Due date, Acceptance criteria и связи с Git-коммитами/PR.
3. Сохраните скриншоты из YouTrack; лучше без приватных токенов/лишних личных данных.
4. В Microsoft Word создайте временный документ; вставьте каждый скриншот на отдельную страницу с краткой подписью («Board overview», «Task ...»). Файл → Сохранить как → PDF. Получится **один** PDF с реальными скриншотами.
5. Откройте PDF и убедитесь, что все ID и поля читаемы. Не используйте HTML-макет прототипа в качестве скриншотов YouTrack.
